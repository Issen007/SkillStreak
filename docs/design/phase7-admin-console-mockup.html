AD3 — Bug-report triage queue The one place in this console that shows an individual child — deliberately, per Decision 7, and deliberately not a drill-down: no reporter column in the list, no filter/search by player, no "other reports by this player" link. All five attacker-controllable strings — description, app version, OS version, and the reporter's screen name and team name, neither of which has any charset validation in the backend — get a visible "verbatim / untrusted" treatment so an accidental innerHTML regression looks wrong. The rule is "every string a user typed", not an enumerated list.
